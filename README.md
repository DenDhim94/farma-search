# 🔍 ФармА-Поиск

**Поиск и бронирование лекарств в аптеках Иркутска**

Версия 9.0 · 29.09.2026 · г. Иркутск

---

## О проекте

«ФармА-Поиск» — веб-приложение для поиска лекарств в аптеках Иркутска и их бронирования через корзину. Все данные предоставляются бесплатно из открытых источников интернета. Проект некоммерческий.

В разработке использованы современные технологии и искусственный интеллект — виртуальный помощник «Алиса» от Яндекса.

### Что внутри

- **Клиентская часть** — умный поиск лекарств с поддержкой синонимов, опечаток и морфологии, корзина брони, оформление заказа
- **Панель персонала** (`/staff`) — просмотр и управление бронями, смена статусов
- **Панель администратора** (`/admin`) — статистика, загрузка остатков из Excel, интеграция с API «Нейрон Фарм», управление аптеками, очистка базы данных
- **Адаптивный дизайн** — ПК, планшеты, телефоны (Android, iOS)
- **Разделение ролей** — персонал и администратор (с проверкой на бэкенде)
- **Полнотекстовый поиск FTS5** — индексный поиск вместо `LIKE` (в десятки раз быстрее на больших объёмах)
- **Пагинация** — по 25 результатов на странице, максимум 100
- **Кэширование** — Redis (с fallback на файл и in-memory)
- **WAL-режим SQLite** — параллельные чтение и запись без блокировок
- **Батчевая обработка** — `executemany()` для вставки/обновления (ускорение загрузки 95 000 строк в 10–30 раз)
- **Умный поиск** — 150+ синонимов бренд → МНН, стеммер, fuzzy-поиск

## Технологии

### Backend

- **Python 3.10+**
- **FastAPI** — веб-фреймворк
- **Uvicorn** — ASGI-сервер
- **SQLite** — база данных (`apteka.db`), WAL-режим
- **openpyxl** — чтение Excel-файлов (`.xlsx`)
- **python-multipart** — обработка загрузки файлов
- **requests** — HTTP-клиент для API «Нейрон Фарм»
- **redis** — кэширование (токен, результаты поиска)

### Frontend

- **HTML5** — разметка
- **CSS3** — стили (анимации, медиа-запросы, safe-area, печать)
- **JavaScript** (встроенный в HTML) — логика без фреймворков
- **Google Fonts** — Manrope, PT Sans, JetBrains Mono

### Внешние сервисы

- **API «Нейрон Фарм» (NiRON)** — товароучётная система
  - Хост: `hsvc.oasis38.ru`
  - Базовый путь: `/farmtech/v1`
  - Аутентификация: OAuth2 `client_credentials` → JWT (24 часа)
  - Кэш токена: Redis + `token_cache.json` (fallback)

### Кэширование

- **Redis** — основной кэш (токен, результаты поиска)
- **`token_cache.json`** — fallback при недоступности Redis
- **In-memory dict** — fallback при недоступности и Redis, и файла

```bash
python3 -m venv .venv
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

Установятся: `fastapi`, `uvicorn`, `openpyxl`, `python-multipart`, `requests`, `redis`.

```bash

sudo apt install redis-server
sudo systemctl start redis-server

# macOS (Homebrew)
brew install redis
brew services start redis

# Windows (через Docker)
docker run -d --name redis -p 6379:6379 redis:alpine
```

### FTS5 — полнотекстовый поиск

Виртуальная таблица `excel_stock_fts` использует FTS5 (встроен в SQLite). Поиск через `MATCH` вместо `LIKE '%term%'` — индексный, в десятки раз быстрее. Триггеры автоматически обновляют FTS-индекс при вставке/обновлении/удалении.

```sql
SELECT es.*, p.address, p.phone
FROM excel_stock_fts fts
JOIN excel_stock es ON es.id = fts.rowid
LEFT JOIN pharmacies p ON CAST(es.dep_code AS INTEGER) = p.code
WHERE excel_stock_fts MATCH ?
ORDER BY rank
LIMIT ? OFFSET ?
```

## Умный поиск

### Этапы

1. **Валидация** — длина 2–100 символов, только буквы/цифры/пробелы
2. **Нормализация** — `trim`, `lowercase`, удаление лишних пробелов
3. **Синонимы** — замена брендов на МНН (150+ соответствий)
4. **Стеммер** — отсечение русских окончаний (`-ая`, `-ое`, `-ые`, `-ой`, `-ыми`, `-ами`, `-ах`, `-ов`, `-ев`, `-ие` и др.)
5. **FTS5 MATCH** — полнотекстовый поиск по индексу
6. **Ранжирование** — `rank` из FTS5 (встроенный BM25)

### Примеры синонимов

- Нурофен → ибупрофен
- Но-шпа → дротаверин
- Конкор → бисопролол
- Глюкофаж → метформин
- Вентолин → сальбутамол

Словарь расширяется в `main.py` — переменная `SYNONYMS_DICT`.

## Кэширование

### Кэш поиска (60 секунд)

- Redis-ключ: `search:{query}|{page}|{limit}` — JSON-результат (TTL 60 с)
- In-memory: `SEARCH_CACHE = {}` — fallback

### Кэш JWT-токена API NiRON

- TTL: 24 часа (86400 сек)
- Buffer: 30 сек (токен считается невалидным за 30 с до истечения)

Структура `token_cache.json`:

```json
{
  "access_token": "eyJhbGciOi...",
  "expires_at": 1790698784,
  "expires_at_iso": "2026-09-29 16:19:44",
  "created_at": "2026-09-28 16:19:44"
}
```

Логика: Redis → файл → запрос нового токена. При любой ошибке старый токен **никогда** не возвращается.

## Слияние остатков (merge_stock)

При загрузке данных из Excel или API NiRON используется слияние, а не полная замена таблицы.

| Ситуация | Действие |
|----------|---------|
| Товар в БД и в incoming, `qty` совпадает | Не трогаем |
| Товар в БД и в incoming, `qty` отличается | `UPDATE qty`, `updated_at=now` |
| Товар в incoming, нет в БД | `INSERT` |
| Товар в БД, нет в incoming | `DELETE` |

**Оптимизация v9.0:** `executemany()` батчами вместо построчных `execute()`. Один `commit` на всю операцию. Ускорение на 95 000 строк: 10–30 раз.

Статистика слияния: `inserted`, `updated`, `deleted`, `skipped`.

## Интеграция с API «Нейрон Фарм» (NiRON)

### Аутентификация

- Endpoint: `{API_BASE_URL}/auth/token`
- Метод: POST
- Тип: OAuth2 `client_credentials`
- Результат: `access_token` (JWT, 24 часа)

### Получение остатков

1. **Список отделений** — `GET /dict/departments` с `Authorization: Bearer {token}`
2. **Остатки по отделению** — `GET /stock?department={code}&cursor={cursor}` с пагинацией через `cursor`
3. **Фильтрация** — пропускаются позиции с `deleted=true`, отрицательный `qty` обрезается до 0
4. **Слияние с базой** — `merge_stock(conn, all_items, "api")`
